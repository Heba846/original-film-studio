# اختبار مونتاج افتتاحية الفيلم

هذه عينة مختصرة مدتها 16 ثانية من الفيديوهات والأصوات الموجودة، وليست المشهد الكامل.

## الحالة الفعلية

- مشروع Remotion مجهز، لكنه لم يُشغّل أو يُختبر لأن تنزيل حزم npm تعطل بسبب اتصال الشبكة.
- فيديو المعاينة صُدّر باستخدام FFmpeg من نفس ملف timeline.json.
- جملة Nico تبدأ عند 12.5 ثانية مع القطع إلى لقطته. هذا ضبط مونتاج وصوت، وليس مزامنة حركة الشفاه.
- توقيت الملفات الصوتية مأخوذ من مدد التسجيلات الفعلية. تقسيم جملة الراوية الطويلة إلى كابشنز تقريبي، وليس تفريغًا بمحاذاة الكلمات.
- أعيد استخدام أجزاء من لقطتي الفيديو في زوايا قص مختلفة لتغطية العينة بالمواد الحالية. لم تُولّد لقطات جديدة.
- لا تزال اللقطات المولّدة تحتوي على أخطاء استمرارية؛ التصدير لا يصلح الشخصيات أو محتوى الفيديو تلقائيًا.

## تشغيل Remotion على جهاز متصل بالإنترنت

افتحي PowerShell في هذا المجلد، ثم اكتبي بالترتيب:

```powershell
npm install
npm start
```

المعاينة ستعرض مشروع Opening. لتصدير فيديو من Remotion:

```powershell
npm run render
```

قد يتطلب التشغيل الأول تنزيل متصفح التصدير. لم تُختبر هذه الأوامر في البيئة الحالية، ولا توجد حزم مثبتة أو ملف قفل ضمن هذه النسخة.

## التعديل

- timeline.json: ترتيب اللقطات والتوقيت والصوت والكابشنز.
- public: ملفات الفيديو والصوت الأصلية المستخدمة.
- src/index.tsx: تركيب الفيديو برمجيًا.
- output/Opening_Preview.mp4: نسخة المشاهدة المصدّرة بـFFmpeg.
- render_preview.py: إعادة تصدير المعاينة. يحتاج Python وFFmpeg وFFprobe على PATH أو مساريهما في OFS_FFMPEG وOFS_FFPROBE.

لا تحتاج إعادة المونتاج إلى صرف كريدت من Flow. إنتاج لقطات جديدة يحتاج خدمة توليد فيديو منفصلة.
